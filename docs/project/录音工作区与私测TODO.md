## 明确不做清单（Non-Goals）

为守住听笺「macOS 原生轻量、零数据库、纯文件即资料库」的产品基因，明确不做以下方向：
1. 不做应用内富文本/双向链接笔记编辑器（编辑与知识管理交给 Obsidian）。
2. 不引入 SQLite/CoreData 数据库接管资料库（永远 100% 镜像磁盘文件夹）。
3. 不自建云同步、账号登录或托管 AI 计费（沿用本地文件 + 用户自带同步盘与网关）。
4. 不捆绑数 GB 第三方本地语音模型（继续依托 Apple 原生 `SpeechAnalyzer`）。
5. 不做多人会议纪要、说话人分离或复杂任务看板（聚焦中文课堂与个人长语音记录）。

## 问题背景与用户历史反馈记录

- **实时转写漏识和延迟（2026-11-19 / 11-20 反馈）**：声音较小、音调较低时曾出现零碎识别与十秒以上延迟（构建 21 合成基线首字 12.2 秒）。构建 22–23 已将合成首字降至 1.1 秒、原音 `ΔRMS = 0.00 dB`，前 4 组基准全过；极端组合弱音仍未达 80% 门禁，留待 Phase 0 真机试用与 Phase 5 支线 A 跟进。
- **录音名称与保存结果不一致（2026-11-19 反馈）**：普通录音带日期前缀、拖放占位不带日期前缀且界面五处展示不统一；纳入 Phase 4 统一展示与重命名交互。
- **重命名后的显示滞后（2026-11-19 反馈）**：构建 23 已修复两处直接刷新根因（`loadChildren(force: true)` 并发吞刷改队列补刷、`renameEntry`/`moveEntry` 扩展强刷至缓存及当前目录）并消除 `DirectoryDetail` 主线程同步读盘，待 Phase 0 桌面实操复验。
- **合盖收音极小（资料核实）**：[Apple 硬件麦克风断开说明](https://support.apple.com/guide/security/hardware-microphone-disconnect-secbbd20b00b/web) 确认 Apple 芯片 Mac 笔记本合盖时硬件断开内置麦克风；纳入 Phase 3 事前拦截与引导，真机验证参照 [Apple 输入设置说明](https://support.apple.com/guide/mac-help/mchlp2567/mac)，不修改系统默认输入设备。
