## 明确不做清单（Non-Goals）

为守住听笺「macOS 原生轻量、零数据库、纯文件即资料库」的产品基因，明确不做：
1. 应用内富文本/双向链接笔记编辑器（交给 Obsidian）。
2. SQLite / CoreData 数据库接管资料库（永远 100% 镜像磁盘文件夹）。
3. 自建云同步、账号登录或托管 AI 计费（沿用本地文件 + 用户自带同步盘与网关）。
4. 捆绑数 GB 第三方本地语音模型（依托 Apple 原生 `SpeechAnalyzer`）。
5. 多人会议纪要、说话人分离或复杂任务看板（聚焦中文课堂与个人长语音记录）。
