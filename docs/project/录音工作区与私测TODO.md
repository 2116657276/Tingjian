## 合盖收音：资料与待排查事项

用户反馈 Mac 合盖时麦克风收音音量特别小，切换到耳机后正常；应用内切换麦克风功能正常。此项作为资料调研和使用条件排查，不作为已确认的程序缺陷。

Apple 的[硬件麦克风断开说明](https://support.apple.com/guide/security/hardware-microphone-disconnect-secbbd20b00b/web)指出，Apple 芯片 Mac 笔记本在合盖时通过硬件断开内置麦克风，软件无法启用。若当时选用的是内置麦克风，这可以解释合盖无法正常收音，但不能仅凭反馈确定当时实际输入源或微弱声音来源。当前代码通过 AVCaptureDevice 选择输入设备；录音开始时固定输入，支持主动切换，未据此实测合盖行为。

- [ ] 在用户方便时核实实际 Mac 型号、系统版本、合盖前后听笺中选中的输入设备与运行条件；对比开盖内置麦克风、合盖内置麦克风和合盖外接麦克风的系统输入指示及录音结果。不要修改用户默认输入设备。必要时参照 [Apple 输入设置说明](https://support.apple.com/guide/mac-help/mchlp2567/mac)检查所选设备及输入音量。
- [ ] **合盖且使用内置麦克风时阻止开始录音。** 开始录音前尝试检测 Mac 是否合盖，并识别实际使用的输入设备；若确认已合盖且输入为内置麦克风，提示内置麦克风无法收音、引导选择耳机或其他外接麦克风，并拒绝开始录音。选择「系统默认」时应先判断其实际指向的设备，避免阻止默认输入已是外接麦克风的情况。先调研可靠的系统检测方式与无法确定状态时的处理，再实现并在真实设备上验证；不修改系统默认输入设备。

3. [x] **提供根目录入口和明确的录音目标。** 浏览目录与选择录音目标分开。普通新建使用资料库根目录，「在此录音」使用指定项目，两者都可切回根目录。录音启动时固定本次目标。
4. [x] **在侧栏提供录音暂存区。** 平铺显示草稿，顶部标签仅显示文稿和音频，保留既有草稿及恢复状态。继续支持新建、选择、命名、关闭及恢复草稿。点击开始后建立真实会话，同一时间只录一份。保存成功移除对应草稿，失败保留重试；普通录音保存到根目录，明确指定项目时依该选择保存。见 [构建 10 根目录与录音草稿验证](../verification/2026-11-19/构建10根目录与录音草稿验证.md)。
   - [x] **第二阶段前置调整。** 资料库根目录置于侧栏列表顶部，录音暂存区紧邻项目树。构建 14 已通过桌面布局检查。
5. [x] **支持暂存区和项目文件拖放。** 构建 14 重做两类拖放接入，底层占位交付回归通过，用户实测确认可用。见 [构建 14 根目录与拖放验证](../verification/2026-11-19/构建14根目录与拖放验证.md)。拖入未开始的草稿后创建空目录并绑定，录完后填入同一目录。再次拖放移动已绑定的空目录，关闭草稿保留空目录。处理外部删除、替换或写入冲突，保留录音并允许重选。项目树内沿用独立文件与整份录音的移动规则。见 [构建 11 绑定交付与连续纠正验证](../verification/2026-11-19/构建11绑定交付与连续纠正验证.md)。
6. [x] **连续多段纠正并映射回原时间轴。** 用户手动试读两种纠正方式通过。 现有实现已将相邻段落成批发送，但提示词要求保持原段落边界。复用现有分块、上下文和 JSON 校验，让模型先把同一批连续的 N 段当成一段话通读和纠正，再按原语义位置分回 N 个原始段落 ID。
   - **批内纠正。** 允许跨相邻段修复断词和断句，删除口吃、无意义的语气词及跨段复述，按句意整理标点。保留有意义的提问、教学强调、否定、数字和术语。比如把前段末尾「风力呢有两种取……」与后段开头「取值，就是强和弱」接起来，只保留一次「取值」，并把「强和弱」留在对应的原时间附近。
   - **批间衔接。** 按现有字符和段数上限分块，优先在语意完整处切分。批次首尾复用少量相邻段作参考，每段只由所属批次输出。块边界的重复优先依据上一批已经保留的文字清理当前批开头，避免两边同时删。遇到输出截断，沿用缩小批次重试，并保留新边界的相邻上下文。
   - **返回与保存。** 每个原 ID 按顺序返回一次，客户端用原 ID 关联原时间戳。纯语气词或完全重复的段可返回空文本，校正版保留对应时间锚点，并检查保存后重新打开仍能读取。全部结果通过结构校验后另存校正版，保留原稿。更新纠正缓存版本，重跑时使用新逻辑。
   - **验收。** 用合成文稿覆盖同批和跨批复述、跨段断词、连续语气词、异常标点、应保留的真实问句或强调、空段与时间戳回读，以及错序、缺段和截断。用户手动对照合成样本的原稿和校正版，检查连贯性、信息保留和时间定位。
7. [x] **加入首次设置与纠正偏好。** 两种纠正方式经用户手动试读通过。 引导设置保存位置和可选纠正配置，升级时补齐缺项。支持默认的轻度清理和全面书面化。两种偏好共用第 6 项的连续段落纠正和时间戳映射，按偏好区分缓存。
