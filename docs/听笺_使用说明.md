# 听笺使用说明

日常使用版位于 `/Applications/听笺.app`，项目内 `dist/听笺.app` 为测试版，当前两者为同一构建，版本号均为 1.0.1（构建 2）。正式保存位置沿用 iCloud Obsidian 的听笺目录。课程名可留空，点击开始才采集麦克风；首次使用按系统提示授权。暂停期间不采集，继续后时长累加。结束后等待保存状态完成，再打开文件夹。

## 项目工作区

保存位置就是资料库根目录，左侧直接显示磁盘上的文件夹与文件，不使用数据库。每次录音在那里生成独立文件夹；文件夹直属内容至少有一个受支持的音频文件时，侧栏会标成录音文件夹。支持的音频为 m4a、caf、wav、aiff、aif、mp3，文稿为 md；其他文件不显示，但改名或移动时不会被删除。

展开文件夹时才读取其子项。上方按钮可新建录音、新建项目与刷新；下方是设置和保存位置入口。应用重新激活、手动刷新以及应用自身的改名、移动、保存后都会刷新对应目录，不做后台轮询。根目录不存在时显示空资料库，第一次录音或新建项目时才创建；无权限或目录不可读会显示实际路径和错误。

重命名：选中侧栏行或文档页操作，也可用 ⌘⇧R。文件名保留扩展名，非法名称、重名、点目录、符号链接和根目录改名都会被拒绝。改名音频或文稿时，同一目录中由本应用写入的 `[[名称]]`、`![[名称]]` 引用（包括校正版的“原始转写”链接）会同步更新；写入失败会回滚文件与文稿字节，回滚失败会列出实际路径。目录改名只改变文件夹名，内部文件与正文不变。

移动：右键“移动到…”选择当前资料库内的目录，或把侧栏行拖到目录行。录音文件夹内的文件按“整份录音及文稿”移动，避免拆散音频与配对文稿；普通目录或独立文件按自身移动。目标为自身、子目录、资料库外、同名或符号链接时拒绝；同一父目录返回原位置。

录音、收尾、待重试保存的目标目录及祖先，以及正在纠正的源文稿，不能被改名或移动；录音进行中界面也会禁用这些操作。外部移动或删除当前选中文件时，主区显示“文件已移动或不存在”，用顶部刷新按钮重新读取。

## 录音与输入设备

设置或录音控制带中的输入设备按系统 uniqueID 固定，不修改系统默认设备。“系统默认（开始时固定）”只在开始录音时解析一次默认设备。录音中可以直接切换设备：同一份录音继续，切换期间不产生音频，也不插入虚构静音；结束后 Markdown 的“说明”会记录原设备、新设备与切换时间。暂停中切换设备不会自行开始采集。

当前设备断开时录音转为暂停并显示补救入口，不会结束录音或悄悄改用别的麦克风；继续或更换设备后可接着录，也可以直接结束保存已录部分。运行时的输入错误只尝试用同一设备重建一次，失败即暂停。权限只在点击开始时申请；无设备或权限被拒绝会保持空闲并说明原因。开始、暂停、继续与切换的操作串行执行，重复点击不会启动多个音源。

保存目标在开始录音时固定：之后更改设置中的保存位置不会影响本次会话，保存和重试都写开始时的目标。待保存或保存失败时禁止开始新录音，先重试保存，避免丢掉本地补救入口。

## 转写与保存

默认使用 Apple SpeechAnalyzer / SpeechTranscriber 的简体中文模型。模型不可用或转写异常时，录音仍可保存；不要将“部分完成”当作完整转写。没有文字也可能是静音。设置中可从已保存录音重新转写，另存文件；重名时自动追加序号，保留已有编辑。

默认目标：`~/Library/Mobile Documents/iCloud~md~obsidian/Documents/听笺`。设置中可改目录。每次会话包含 M4A 和带时间戳的 Markdown；校正版另存。状态“已写入目录”只表示本地写入结果，不表示云端同步完成，云同步情况在状态详情中不承诺。

本地恢复目录：`~/Library/Application Support/听笺/Sessions`。录音过程中持续保存 CAF、会话信息和会话日志；目标目录写入失败时保留本地内容，可重试；转换失败时保留 CAF。异常退出后重启会提示恢复并保存。已成功交付的本地备份可在设置中移入废纸篓。

如果出现“文本/恢复信息保存异常”，音频会继续保存，界面显示本地路径；应用会在定期保存和结束时尝试重建日志。异常未解除前不要把全部内容视为保存成功。开始准备失败不会启动麦克风。

录音中退出会询问结束并保存或继续录音；选“继续录音”会取消本次退出并恢复窗口。睡眠与合盖仍不承诺持续录音。

## 文稿阅读与播放

主区一次只显示一份文稿或音频。文稿中的 `[HH:MM:SS] 文本` 以 16pt 正文显示，点击时间戳会定位到关联音频的对应位置；超出音频时长、没有关联音频或正在录音时不可定位。引用 `![[音频文件名]]` 指向同目录实际存在的音频时才加载播放器；缺失时会说明，但文稿仍可阅读。没有时间戳的普通 Markdown 显示原文，不猜配对、不丢弃内容。应用只有一个播放器，换文件会停止旧音频。

## 主题与设置

设置分“外观”“录音输入”“保存与恢复”“文字纠正”。外观可选跟随系统、浅色、深色，立即生效并在重启后保留；主窗口与设置窗口同步。浅色为暖白纸感，深色为墨绿纸面，状态同时使用图标与文字。

## Magpie 纠正

默认地址 `http://127.0.0.1:3425/v1`，默认模型 `sdu/ByteDance-volcengine/DeepSeek-V4.1-Flash`，强度 high。设置中刷新模型清单，选择支持纠正的模型及其强度；无法读取清单时可手填。API Key 需要时填写，正常模式存系统钥匙串。

纠正以当前打开的文稿为单位：只在你点击“纠正文本”时发送该文稿的转写文字，不发送录音与时间戳。请求与回复都是 `{"items":[{"id":1,"text":"..."}]}`，客户端保留原时间戳。按字符数与条数分块、保持顺序；模型明确因长度截断时会把多段块对半拆分重试。拒绝回答、HTTP 错误、格式不合法、段落数量或 id 顺序不一致都会失败，不自动修复、不改写原稿。写出前会重读原稿，若被外部修改会提示重新纠正。全部成功后才另存 `_校正版.md`；原稿与录音不受影响。一次只运行一个纠正任务，进度按已完成原文段数显示；切换到其他文稿不会串进度。

## 构建与隔离验证

源码在仓库根目录，文档在 `docs/`。无需完整 Xcode 或第三方依赖，在工程目录运行 `bash scripts/build_app.sh`；需要 Swift、macOS SDK、codesign、iconutil、trash。脚本输出仓库内的 `dist/听笺.app`，采用本地 ad-hoc 签名，不安装到 Applications。

验证工具：先执行 `. scripts/env.sh`，再运行 `swift build --disable-sandbox --scratch-path /tmp/tingjian-build --product tingjian-check`。二进制为 `/tmp/tingjian-build/debug/tingjian-check`，可加 `--real`、`--magpie`、`--long`、`--real5`。运行时使用 `TINGJIAN_CHECK_ROOT=/tmp/新的独立测试目录` 指定隔离路径，勿依赖 TMPDIR。系统语音服务和 AAC 编码需要正常系统服务访问环境。

UI 验证时同时传入 `TINGJIAN_TEST_ROOT`（本地和目标目录隔离）与 `TINGJIAN_TEST_AUDIO`（合成音频），例如 `open --env TINGJIAN_TEST_ROOT=/tmp/tj-test --env TINGJIAN_TEST_AUDIO=/tmp/synthetic.aiff 听笺.app`。只传 `TINGJIAN_TEST_ROOT` 时使用真实麦克风，请确认这是你要测试的设备。
