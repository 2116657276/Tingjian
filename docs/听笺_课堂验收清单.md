# 听笺：30 分钟课堂验收

- [ ] 开课前授权麦克风，确认输入音量有变化，保存路径正确。
- [ ] 在设置中选择实际要用的输入设备；录音中切换到另一个设备，回听切换前后，确认 Markdown 说明记录了设备名与切换时间。
- [ ] 录音中让当前设备断开（或拔掉），确认转为暂停而不是结束或改用其他麦克风；继续或更换设备后能接着录，也可以结束保存已录部分。
- [ ] 开始后课堂进行时持续出现中文文字；记录长时间有讲话却不出字的时段。
- [ ] 录制约 30 分钟；中途暂停约 20 秒再继续，计时暂停且没有收录暂停期间声音。
- [ ] 留意最终文字是否重复堆叠、整段覆盖或系统性丢失句尾。
- [ ] 结束后等待保存完成，无需手动导出即可找到 M4A 与 Markdown。
- [ ] 在侧栏新建项目、改名一份录音目录并移动一份录音，确认 Finder 中路径与 Markdown 内 `![[...]]` 引用一致；文件夹内音频与文稿没有被拆开。
- [ ] 播放开头、中间、末尾，确认音频完整、时长不含暂停时间；核对文本时间戳。
- [ ] 检查 Markdown 日期、时长、引擎语言、转写状态及音频相对链接。
- [ ] 可选：主动纠正文本，确认另存校正版、时间戳对应且原稿保留。
- [ ] 如果目标保存失败，确认界面给出本地路径，能找到 CAF、会话信息与已确认文本，并可重试。
- [ ] 在另一设备确认 iCloud 文件确已同步；应用的“已写入目录”不作为云同步证明。

异常退出、睡眠、设备变化建议另做短录音验证，避免用唯一的重要课堂录音测试故障。
