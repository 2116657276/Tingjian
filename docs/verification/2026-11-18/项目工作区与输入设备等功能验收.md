# 项目工作区与输入设备等功能验收

> **历史记录，描述 2026-11-18 当时的构建和验证；当前版本状态见 [当前版本与验收状态](../../project/当前版本与验收状态.md)。**

## 范围

本轮把主界面从单份文稿阅读器改为资料库工作区，并完成三项底层改造：

- 新增 `ProjectLibrary`：真实文件夹项目树、新建项目、需确认的改名、引用同步、文件与整份录音移动、符号链接和受保护路径校验。
- 新增 `PlaybackModel`：应用内单一播放器、播放位置轮询、文稿时间戳定位、文档关联音频解析。
- 输入设备：`AudioSource` 开始/重建改为异步；`MicrophoneSource` 改用 `AVCaptureSession` 按 uniqueID 固定设备，48 kHz Float32 单声道、无处理，转换到识别格式后交付；录音中切换设备、断连暂停与同设备一次重建。
- 文字纠正：改为 `{"items":[{"id":1,"text":"..."}]}` 请求与回复协议，新增宽松扫描器、id/顺序/数量校验、拒绝与长度截断处理、按字符数与条数分块、取消与进度。
- `Recorder` 保存目标在开始时快照；待保存/失败会话阻碍新录音；恢复会话以恢复时所选目标为准；旧会话保存重试仍写原目标。
- `AppModel` 纠正状态按文稿 URL 归属，只允许一个纠正任务；改名/移动后重映射选中项、已展开目录、播放器与纠正来源。
- GUI 改为侧栏项目树 + 单文稿/音频主区 + 播放条 + 常驻录音控制带 + 状态详情；新增浅色/深色/跟随系统外观与四组设置。

新增文件：`Sources/TingjianCore/ProjectLibrary.swift`、`Sources/Tingjian/PlaybackModel.swift`、`Sources/Tingjian/Theme.swift`。删除 `AudioWidgets.swift`，其令牌并入 `Theme.swift`。
