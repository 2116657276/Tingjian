## 隔离手动验收

从工程根目录用新测试目录和合成音频启动。

```sh
tingjian_trial="$(mktemp -d /tmp/tingjian-placement-manual.XXXXXX)"
say -o "$tingjian_trial/sample.aiff" "风力有两种取值，就是强和弱。"
TINGJIAN_TEST_ROOT="$tingjian_trial" TINGJIAN_TEST_AUDIO="$tingjian_trial/sample.aiff" \
  "dist/听笺.app/Contents/MacOS/Tingjian"
```

1. 新建两个项目，把已命名的草稿拖到第一个项目，再拖到第二个项目。核对空文件夹只移动一次，草稿显示新路径。录完后核对音频和文稿位于该空文件夹。另建一份草稿测试关闭后目录是否保留。
2. 录音开始后，在 Finder 向另一份绑定目录放入一个测试文件。结束后应看到待保存，测试文件仍在。选择「更换保存位置」，选择测试资料库内的新父目录，检查录音和文稿成功导出。
3. 在隔离资料库内建立包含下述片段的 Markdown，刷新后打开，使用已配置的网关纠正文稿。对比原稿和校正版，检查跨段断词、重复和语气词，保留实际提问和原时间戳。

```markdown
# 连续纠正样本

## 转写

[00:00:00] 风力呢有两种取……
[00:00:05] 取值，就是强和弱，对吧？？
[00:00:10] 呃，嗯，那么……
[00:00:15] 那如果风力强，分类结果会变吗？
```

桌面拖放和真实模型的文字质量待用户手动验收。
