验证日期：2026-11-25。对应 [1.0.2（构建 31）产品全面评审](../../reviews/2026-11-25-1.0.2构建31产品全面评审.md) 与 [录音工作区与私测 TODO](../../project/录音工作区与私测TODO.md)「功能冻结期 · Build 32 纯缺陷收口清单」（零新特性、严守 5 条 Non-Goals 与视图层 0 `@State` 宏风格）。全部自动化测试在全新独立隔离临时目录与合成音频上执行，未触碰正式资料库、iCloud、用户设置、默认输入设备、系统钥匙串及稳定版 `/Applications/听笺.app`，未提交 Git。

## 1. 修复范围汇总（分 3 阶段收口）

### 阶段 1 · 核心可靠性与状态机底线修复（`TingjianCore` + 离线测试）

1. **P1-1 · `RecordingPlacement` 判空与交付忽略 `.DS_Store`**（[RecordingPlacement.swift](../../../Sources/TingjianCore/RecordingPlacement.swift)、[PlacementRegression.swift](../../../Sources/tingjian-check/PlacementRegression.swift)）：新增 `fileprivate static func effectiveEntries(in:)` 仅过滤 `.DS_Store`（不放行其他隐藏/外部文件），统一用于 `validateEmpty()` 与 `Deliverer.fill()` 三处检查；新增 3 项回归断言（含 `.DS_Store` 判空/移动/交付/幂等重试、断点续传、含 `.foreign` 仍抛 `.occupied`）。
2. **P1-2 · `onEngineFailure` 清理磁盘 `volatile.json` 且强退恢复保留 `> ⚠` 缺口**（[Recorder+Engine.swift](../../../Sources/TingjianCore/Recorder+Engine.swift)、[Recorder+Recovery.swift](../../../Sources/TingjianCore/Recorder+Recovery.swift)、[Regression.swift](../../../Sources/tingjian-check/Regression.swift)）：`onEngineFailure` 在 `assembler.clearVolatile()` 后紧跟 `clearVolatileSnapshot()`；`recover(dir:)` 将草稿终点改为 `end = start`，有草稿时按 `dur - assembler.lastEnd > 1.0` 补标缺口，无草稿保持 `dur > assembler.lastEnd`；新增 2 项回归断言。
3. **P2-5 · `AudioExporter.exportM4A` 防 `NaN` 绕过与格式化防崩溃**（[Export.swift](../../../Sources/TingjianCore/Export.swift)、[Regression.swift](../../../Sources/tingjian-check/Regression.swift)）：`ExportError.durationMismatch` 经 `formatSeconds` 判断 `.isFinite && >= 0 && < Double(Int.max)`（非有限值输出「无效」防 `Int(NaN)` runtime trap）；`exportM4A` 校验 `sampleRate.isFinite && sampleRate > 0` 与 `dur.isFinite, expected.isFinite, abs(dur - expected) <= 1.0`；新增 NaN/Inf 格式化与 0 字节 CAF 抛错断言。
4. **P2-6 · 换麦 `prepare()` 期间并发 `pause()` / 旧麦断开防状态机分裂**（[Recorder.swift](../../../Sources/TingjianCore/Recorder.swift)、[Regression.swift](../../../Sources/tingjian-check/Regression.swift)）：`pause()` 改为 `await runInput { await self.source?.pause() }`；`switchInput` 仅在 `wasRecording && self.phase == .recording` 时 `candidate.start()` 并同步收口 `inputIssue` 与切换说明；`inputDeviceDisconnected` 入口增加 `!isChangingInput` 守卫；新增 2 项并发换麦断言。
5. **P2-7 · 睡眠唤醒恢复走 `HardwareInputGuard` 校验且睡眠说明落盘**（[Recorder+Engine.swift](../../../Sources/TingjianCore/Recorder+Engine.swift)、[Regression.swift](../../../Sources/tingjian-check/Regression.swift)）：`recoverInput` 重建前执行 `HardwareInputGuard.blockReason` 校验，命中则暂停、设 `needsInputRebuild`/`inputIssue`、记说明并 `persistMetadata()`；`willSleepNotification` 写 `addNote` 后补 `persistMetadata()`；新增唤醒合盖拦截离线断言（真机合盖与睡眠唤醒仍待实测）。
6. **P2-9 · 实时录音全程 0 字状态与重转写对齐**（[Recorder.swift](../../../Sources/TingjianCore/Recorder.swift)、[Regression.swift](../../../Sources/tingjian-check/Regression.swift)）：`stop()` 在有效文本为 0 且 `engineOK` 时落盘 `.partial` 并附「本次录音未识别出文字（可能为静音、设备无有效输入或音频过弱）。」；同步更新 `Regression.swift` 两处 `QuietEngine` 预期并校验说明文案。
7. **P3-4 + 阶段 2 钩子**（[Recorder.swift](../../../Sources/TingjianCore/Recorder.swift)）：`stopTicking(endActivity: Bool = true)` 在 `stop()` 中传 `false` 并以 `defer { endActivity() }` 延后至导出与交付收尾完成再释放 `ProcessInfo` 活动断言；新增 `public func clearMessage()`。

### 阶段 2 · 应用状态层与交互层修复（`Tingjian` + 保护断言）

1. **P2-8 · 重转写与未完成占位目录保护及开录双向互斥**（[AppModel+Library.swift](../../../Sources/Tingjian/AppModel+Library.swift)、[AppModel+Recording.swift](../../../Sources/Tingjian/AppModel+Recording.swift)、[Regression.swift](../../../Sources/tingjian-check/Regression.swift)）：`syncProtection()` 追加 `retranscribingAudioURL` 与 `unfinished` 中会话的 `recordingPlacement?.directory`（不误锁 `saveRoot`）；`canStartRecording` 增加 `!isRetranscribing && !isCorrecting`；新增 4 项目录保护离线断言。
2. **P2-1 · 录中改名输入框防吞空格与防抖/停录前落盘**（[AppModel.swift](../../../Sources/Tingjian/AppModel.swift)、[AppModel+Recording.swift](../../../Sources/Tingjian/AppModel+Recording.swift)、[RecordingView.swift](../../../Sources/Tingjian/RecordingView.swift)、[TingjianApp.swift](../../../Sources/Tingjian/TingjianApp.swift)）：拆分 `activeCourseNameDraft` 与 300ms 防抖同步、`onSubmit`/`onDisappear` 与停录/退出前单向 `flushActiveCourseName()`，不反向覆写输入态。
3. **P2-2 · 空格键全局监听限定主窗口并避开设置/弹窗态**（[AppModel.swift](../../../Sources/Tingjian/AppModel.swift)、[TingjianApp.swift](../../../Sources/Tingjian/TingjianApp.swift)）：增加 `mainWindow` 引用与显式窗口过滤（排除设置窗、`NSPanel`、`attachedSheet`、`NSApp.modalWindow`），并校验 `!showIssues && !stopConfirmationRequested`。
4. **P2-3 · 音频详情页补播放入口与窄窗操作栏折行**（[AppModel+Documents.swift](../../../Sources/Tingjian/AppModel+Documents.swift)、[PlaybackControlBand.swift](../../../Sources/Tingjian/PlaybackControlBand.swift)、[DirectoryAndAudioViews.swift](../../../Sources/Tingjian/DirectoryAndAudioViews.swift)）：新增 `closePlayback()`（保存进度后停止并清高亮）与 `playAudio(_:)`；`AudioDetail` 未加载当前音频时首位展示「播放音频」，操作栏改用 `ViewThatFits(in: .horizontal)` 折行。
5. **P2-4 · 普通 `.md` 笔记禁用/隐藏 `⌘F` 页内查找**（[AppModel+Documents.swift](../../../Sources/Tingjian/AppModel+Documents.swift)、[DocumentDetailView.swift](../../../Sources/Tingjian/DocumentDetailView.swift)）：`canSearchCurrentDocument` 要求 `blocks` 非空，切换至普通 `.md` 时自动收起搜索条，顶栏仅对带时间戳文稿显示「查找」。
6. **P2-10 · 报错横幅自动清空/可关闭与右上角 `…` 菜单一致**（[AppModel.swift](../../../Sources/Tingjian/AppModel.swift)、[AppModel+Recording.swift](../../../Sources/Tingjian/AppModel+Recording.swift)、[PlaybackControlBand.swift](../../../Sources/Tingjian/PlaybackControlBand.swift)、[ContentView.swift](../../../Sources/Tingjian/ContentView.swift)）：选麦/换麦成功清 `recorder.clearMessage()`，交付完成清 `inputSwitchError`；仅对一次性提示类 issue（`start`/`message`/`input-switch`/`library`/`seek`）在 `IssuesPopover` 提供「知道了」；右上角 `…` 菜单「纠正文本」改与顶栏一致（仅 `lines` 非空且 `llmEnabled` 时显示）。
7. **P3-3 · 发往 LLM 语境剔除 `## 说明` 与库外父目录名**（[AppModel+Correction.swift](../../../Sources/Tingjian/AppModel+Correction.swift)）：元信息截取遇到任何 `## ` 即止，且仅对位于 `saveRoot` 内的父/祖目录附带目录名。

### 阶段 3 · 可选 UI P3 质感微修、标点清扫与 Build 32 打包
