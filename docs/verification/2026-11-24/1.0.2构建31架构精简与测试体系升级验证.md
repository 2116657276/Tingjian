## 1. 阶段 2.0–2.4 改动清单

### 阶段 2.0 · 核心纯逻辑抽离与测试体系升级
- **抽离无 UI 依赖核心状态工具**：新建 [WorkspaceState.swift](../../../Sources/TingjianCore/WorkspaceState.swift)（105 行），提供 `WorkspacePathMapper`（路径重映射、字典重映射与标签页去重）及 `DocumentHighlightResolver`（播放时间轴当前段落高亮定位，完整兼容隐藏校正版空锚点语义）。
- **测试基础设施收口**：新建 [TestSupport.swift](../../../Sources/tingjian-check/TestSupport.swift)（172 行），集中 `TestCounter`、`IntLog`、`finishAndExit`（统一输出 `总计：通过 N / 失败 M（耗时 X.XXs）`）、`MockURLProtocol` 与 `MockLLMFixture`，消除 [main.swift](../../../Sources/tingjian-check/main.swift) 与 [CorrectionRegression.swift](../../../Sources/tingjian-check/CorrectionRegression.swift) 中的重复 HTTP/JSON 测试桩构造。
- **默认回归全量纳管与新增单测**：新建 [WorkspaceStateRegression.swift](../../../Sources/tingjian-check/WorkspaceStateRegression.swift)（109 行，新增 10 项断言覆盖子路径、兄弟/同前缀目录、symlink 规范化、字典覆盖、标签页去重与隐藏空锚点高亮）；将 `recordingPlacementChecks()`（8 项）、`continuousCorrectionChecks()`（9 项，尊重 `--skip-correction`）与 `workspaceStateRegressionChecks()`（10 项）统一接入默认离线回归，同时保留 `--placement-only` / `--correction-only` 快捷入口。

### 阶段 2.1 · `AppModel.swift` 清理、降重绘与模块化拆分
- **死代码清零**：删除未引用的 `showUnfinished`、`documentSearchFocusRequest`（含赋值）与 `recoverFirst()`。
- **消除滚动全树重绘**：移除 `documentScrollAnchors` 与 `documentScrollPoints` 的 `@Published` 修饰，保留同名存储属性及读写接口。
- **消除重复构造并接入 `TingjianCore`**：为 `OpenDocument` 新增 `remapping(_:)`，替换 `remapPaths` 中两处 12 字段重复构造；`AppModel+Library.swift` 接入 `WorkspacePathMapper`（移除本地 `pathMapper`/`remapped`/标签去重与 `import Darwin`）；`AppModel+Documents.swift` 接入 `DocumentHighlightResolver.activeBlockID(...)`。
- **按职责拆分为 5 文件**：主文件 [AppModel.swift](../../../Sources/Tingjian/AppModel.swift) 瘦身至 656 行，其余拆入 [AppModel+Library.swift](../../../Sources/Tingjian/AppModel+Library.swift)、[AppModel+Recording.swift](../../../Sources/Tingjian/AppModel+Recording.swift)、[AppModel+Correction.swift](../../../Sources/Tingjian/AppModel+Correction.swift) 与 [AppModel+Documents.swift](../../../Sources/Tingjian/AppModel+Documents.swift)。

### 阶段 2.2 · `ContentView.swift` 模块化拆解与去重
- **按页面边界拆分为 7 文件**：主壳保留于 [ContentView.swift](../../../Sources/Tingjian/ContentView.swift)，拆出 [SidebarView.swift](../../../Sources/Tingjian/SidebarView.swift)、[RecordingView.swift](../../../Sources/Tingjian/RecordingView.swift)、[DocumentDetailView.swift](../../../Sources/Tingjian/DocumentDetailView.swift)、[DirectoryAndAudioViews.swift](../../../Sources/Tingjian/DirectoryAndAudioViews.swift)、[PlaybackControlBand.swift](../../../Sources/Tingjian/PlaybackControlBand.swift) 与 [WorkspaceSheets.swift](../../../Sources/Tingjian/WorkspaceSheets.swift)。
- **视图组件去重与 CLT 约束**：将 `DocumentDetail.actionBar` 中 prominent / bordered 两处「重新转写」按钮收口为 `retranscribeButton(audio:prominent:isRetranscribingThisAudio:)`；抽离共享右键菜单组件 `LibraryEntryFileMenuItems` 与 `LibraryEntryManageMenuItems` 复用于侧栏、目录与顶栏菜单；7 个 UI 文件全程保持 0 个 `@State` 宏（沿用 `@StateObject` / `@EnvironmentObject`），外部交互、快捷键与文案 100% 等价。

### 阶段 2.3 · `Recorder.swift` 按链路职责拆分
- **按控制 / 恢复 / 引擎拆分为 3 文件**：[Recorder.swift](../../../Sources/TingjianCore/Recorder.swift)（状态与控制主流程）、[Recorder+Recovery.swift](../../../Sources/TingjianCore/Recorder+Recovery.swift)（未完成会话恢复、导出、交付与重试保存，顺手收口 `recover` 与 `retrySave` 重复的 `existingPublication` 查询）及 [Recorder+Engine.swift](../../../Sources/TingjianCore/Recorder+Engine.swift)（识别引擎回调、实时草稿快照持久化与输入设备/睡眠监听）；全部 `public` API 与语义保持等价。

### 阶段 2.4 · 版本递增与 Release 签名交付
- 更新 [build_app.sh](../../../scripts/build_app.sh)：`CFBundleVersion` 由 `30` 递增为 `31`（`CFBundleShortVersionString` 保持 `1.0.2`），完成 Release 打包与严格签名校验。
