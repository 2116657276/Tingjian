## 1. 分阶段变更汇总

### Phase 1（构建 24）· 文稿阅读真相补全与课后入口前移
- **[Export.swift](../../../Sources/TingjianCore/Export.swift)**：新增 `ParsedDocumentBlock`、`ParsedMarkdownDocument` 与 `MarkdownDoc.parseDocument(_:)`，保持 `parseSegments(_:)` 签名与行为完全不变，解析标题、录制日期、时长、转写状态、`## 说明`、`> ⚠` 转写不完整缺口块、校正版模型名与 `[[原始转写]]` 来源引用，并统计空时间锚点与缺口数。
- **[ProjectLibrary.swift](../../../Sources/TingjianCore/ProjectLibrary.swift)**：新增同目录安全解析 `linkedOriginalDocument(named:beside:)`（拒绝跨目录路径、自引用与符号链接）与 `latestCorrectedDocument(for:)`（选取同目录编号最新的 `_校正版*.md`，跳过符号链接）。
- **[Retranscribe.swift](../../../Sources/TingjianCore/Retranscribe.swift)**：修正 `writeMarkdown` 对 0 段静音输出硬编码 `.completed` 的问题——无有效文字时标 `.partial` 并附原因说明，有文字时标 `.completed`。
- **[AppModel.swift](../../../Sources/Tingjian/AppModel.swift)**、[ContentView.swift](../../../Sources/Tingjian/ContentView.swift)、[SettingsView.swift](../../../Sources/Tingjian/SettingsView.swift)：
  - 重构 `DocumentDetail` 顶部状态与操作区：展示标题、状态徽章（`部分完成` / `转写失败` / `校正版 · 模型名`）、紧凑元信息与可展开「说明」条；前移「纠正文本 / 启用文字纠正…」「查看原稿 / 打开校正版」「重新转写」「外部打开」入口；
  - 新增 `DocumentGapRow` 行内渲染 `> ⚠` 缺口警示（支持点击起点时间回听）；默认折叠校正版删空后的纯 `[HH:MM:SS]` 空时间锚点并提供原地显示/隐藏切换（不改写原文件字节）；
  - 在 `AudioDetail`、侧栏/目录右键菜单与顶部项目菜单补充上下文「重新转写」（共用防重入、录音中拦截与百分比进度，完成后自动打开 `_重转写.md`）及「在默认应用中打开」。

### Phase 2（构建 25）· 课后复习回听四件套
- **[Models.swift](../../../Sources/TingjianCore/Models.swift)**：新增 `Timecode.parse(_:)` 与无 UI 依赖纯算法 `TranscriptLocator`（`activeBlockIndex` 二分定位当前播放段落、`matchingBlockIndices` 大小写不敏感页内查找）。
- **[PlaybackModel.swift](../../../Sources/Tingjian/PlaybackModel.swift)**：支持 `1.0x / 1.25x / 1.5x / 2.0x` 倍速（`.timeDomain` 保音高、持久化到隔离兼容 `UserDefaults`）、`skip(by:)` 步进（`-5s / +10s`）、`playFrom(_:)` 原子定位起播及 `onTimeChanged` 回调。
- **[AppModel.swift](../../../Sources/Tingjian/AppModel.swift)**、[TingjianApp.swift](../../../Sources/Tingjian/TingjianApp.swift)、[ContentView.swift](../../../Sources/Tingjian/ContentView.swift)：
  - 文稿页增加可收起页内查找条（`⌘F` / `⌘G` / `⌘⇧G`，匹配计数与居中滚动高亮）；
  - 播放时仅在跨段时更新 `activeDocumentBlockID` 柔和蓝色高亮当前段，提供可选「跟随播放滚动」开关；点击文稿时间戳直接定位并播放；
  - 控制带补齐 `-5s / 播停 / +10s / 倍速菜单`，顶部新增「查找」与「播放」菜单，非输入态支持空格键播停（局部事件监控，严格跳过文本输入焦点与弹窗）。

### Phase 3（构建 26）· 课中防事故与合盖内置麦拦截
- **[AudioSource.swift](../../../Sources/TingjianCore/AudioSource.swift)**：新增 `HardwareInputEnvironment`、`SystemHardwareInputEnvironment`（IOKit 读取 `IOPMrootDomain` `AppleClamshellState` + CoreAudio `kAudioDevicePropertyTransportType` 识别 `kAudioDeviceTransportTypeBuiltIn`）、`HardwareInputGuard`（支持「系统默认」解引用，状态未知时安全降级放行）与 `AudioSource.requiresHardwareInputGuard`（仅真实 `MicrophoneSource` 为 `true`，文件/合成源默认 `false` 不受合盖影响）。
- **[Recorder.swift](../../../Sources/TingjianCore/Recorder.swift)**：
  - 在 `start`、`resume`、`switchInput` 三处接入合盖内置麦拦截；
  - `courseName` 改为 `@Published` 并新增 `updateCourseName(_:)`（仅更新内存、`store.info.course` 与交付 `store.info.baseName` 并落盘 `session.json`，不动运行中的 `localDir` 与 `audio.caf`）；
  - 新增持续低电平温和静音提醒（`silenceWarning`，默认连续 45 秒有效电平低于 0.015 且无新增转写时触发，检测到有效声音或新文字即刻自动消除，不中断录音）。
- **[AppModel.swift](../../../Sources/Tingjian/AppModel.swift)**、[ContentView.swift](../../../Sources/Tingjian/ContentView.swift)：
  - 录音/暂停期间转写页顶部支持随时补填或修改课程名；
  - 结束快捷键从易与“另存为”冲突的 `⌘⇧S` 调整为 `⌘⇧E`，且录制 ≥ 30 秒时弹出轻量确认防误停；
  - 顶部增加不抢焦点的柔和静音提示条。

### Phase 4（构建 27）· 侧栏时间线、命名展示统一与质感打磨
- **[Support.swift](../../../Sources/TingjianCore/Support.swift)**：新增 `RecordingNameParts`、`Paths.parseRecordingName(_:)`（同时覆盖带课程名与纯日期录音，支持重建保留前缀名）与 `LocalBackupSummary` / `Paths.savedLocalBackupSummary(in:)`（递归统计已交付备份份数与磁盘字节数）。
- **[ProjectLibrary.swift](../../../Sources/TingjianCore/ProjectLibrary.swift)**：新增 `LibrarySortOrder`（`.newestFirst` / `.nameAscending`）与 `sortEntries(_:order:)`（默认普通项目按名称升序在前、带日期前缀录音按时间倒序新课置顶，文件在后）。
- **[AppModel.swift](../../../Sources/Tingjian/AppModel.swift)**、[ContentView.swift](../../../Sources/Tingjian/ContentView.swift)、[SettingsView.swift](../../../Sources/Tingjian/SettingsView.swift)、[使用指南.md](../../guides/使用指南.md)：
  - 侧栏、目录详情、音频详情、文稿顶栏与标签页五处命名展示统一复用 `Paths.parseRecordingName`，侧栏日期录音附紧凑日期副标防撞名；`RenameSheet` 针对日期目录默认仅编辑课程名部分并保留前缀（附「编辑完整磁盘名称」开关）；
  - 后台异步探查一级目录音频标识缓存至 `recordingDirectoryFlags`，解决未展开录音目录在侧栏缺失录音图标的问题；侧栏顶部与右键新增排序切换；
  - 修复 `openTabs` 非空时切回录音/目录页顶栏失去标题的问题；统一侧栏 `+` 与目录页「新建项目…」在录音中禁用；无草稿时隐藏孤立「暂存」标题；
  - 将 `savedLocalBackups()` 移出主线程渲染并异步展示总磁盘占用；持久化已选设备名称替代断连原始 UID；关闭「启用文字纠正」时收起下方网关配置；底栏默认设备菜单智能去重；同步更新 [使用指南](../../guides/使用指南.md) 主题说明与 1.0.2 新功能。
