# 构建 23 评审修复与回归验证

2026-11-24，Apple 芯片 Mac，macOS 27.2，Swift 6.4.2。本轮验证覆盖针对 [构建 22 全面代码评审](../../reviews/2026-11-23-构建22全面代码评审.md) 全部 A 类简单缺陷、编译告警、死代码与文案/菜单一致性的阶段 2 修复，并交付新的测试版应用包 `dist/听笺.app`（1.0.1 构建 23）。全部测试均使用独立临时目录和合成音频，未触碰真实录音、iCloud 目录、用户偏好与钥匙串；事后所有临时构建、运行目录及日志已通过 `trash` 清理。稳定版仍为 `/Applications/听笺.app` 1.0.1（构建 21）。

## 构建 23 改动摘要

- **核心层（`Sources/TingjianCore/`）**：
  - `Recorder.swift`：修正 0 字识别失败会话状态判定，按是否存在 `.text` 事件判断并标为 `.failed`（与 `recover()` 一致）；修复启动准备失败及等待期间 `cancelStarting()` 取消分支对空会话目录的 `trashItem` 清理，避免泄漏空目录或误设 `localDir`。
  - `ProjectLibrary.swift`：`movePlan(for:)` 跳过同目录非当前选中项中的非 UTF-8 `.md` 文件，不再阻塞同目录正常文件移动。
  - `SpeechEnhancer.swift`：类注释明确非线程安全（仅限串行队列调用）；对 `Config` 滤波/AGC/限幅参数补齐 `.isFinite` 与安全范围钳位（默认声学参数不变）。
  - `AudioSource.swift`：`MicrophoneSource` 补充 `@unchecked Sendable`，清零全 `TingjianCore` 原有 5 条 Sendable 告警；补齐 `configureLocked` 失败回滚、`makeBuffer` 帧数边界校验、`FileSource.prepare()` 采样率有限性校验，以及 `FileSource.readNext` 释放锁后再触发外部回调。
  - `AudioPipeline.swift` 与 `Retranscribe.swift`：`drainPCM` 增加 64 次循环上限并将 0 帧 `.inputRanDry` 视作正常排空结束，`Retranscribe.flushConverter` 统一复用 `drainPCM`。
  - `Engine.swift`：`start(callbacks:)` 防范并发取消，并在启动失败时清理 `continuation`、`resultsTask` 与 `convQueue` 临时状态；避免二次包装 `EngineError`。
- **桌面应用层（`Sources/Tingjian/`）**：
  - `AppModel.swift`：`loadChildren(force: true)` 在已有加载任务进行中时记录补刷标记并在任务内循环重扫，避免强刷被吞；`renameEntry` 与 `moveEntry` 扩展强刷范围至已缓存目录及当前详情目录，消除同步改名前缀后界面残留旧文件名。
  - `AppModel.swift` 与 `SettingsView.swift`：重新转写新增 `isRetranscribing` 防重入状态、进度百分比透传与按钮禁用/加载态；清理 `llmConfigured` 冗余逻辑、移除底部重复 `import AVFoundation`，校验 `AVAudioFileDuration` 采样率有效。
  - `AppModel.swift`：`TINGJIAN_TEST_AUDIO` 仅在同时设置 `TINGJIAN_TEST_ROOT` 时生效，防止测试音频误写入正式偏好与目录。
  - `ContentView.swift` 与 `TingjianApp.swift`：`DirectoryDetail.body` 改读缓存的 `model.isRecordingDirectory(url)` 避免主线程同步读盘；`NewProjectSheet` 提示补齐禁止字符 `[ ]`；移除 `StatusBar` 未使用的死代码；顶部「资料库」菜单项禁用条件与详情菜单对齐。
- **验证工具与构建脚本（`Sources/tingjian-check/`、`scripts/`）**：
  - `main.swift`：默认无 `--real` 时改为纯离线回归（不触发依赖本机中文模型的 `Retranscriber` 用例）；清零全部 63 条 Swift 6 编译告警（`failures` 线程安全计数、`MockEngine` 改 `lock.withLock`、清理 28 处冗余 `await`）。
  - `WeakVoiceBench.swift`：校准第二讲稿 `--weak-voice-holdout` 前 4 组门禁为 `关键词召回 >= 80%` 且 `CER <= 8%`（对齐 0 dB 合成基线 12/15 = 80.0%、CER 3.7%），**组合弱音组严格保留 80% 门禁不放宽**。
  - `Regression.swift` 与 `ReviewRegression.swift`：补充 6 条定向回归断言，覆盖 0 字全失败 `.failed` 判定、启动失败/取消不泄漏空目录、混放目录坏编码 `.md` 不阻塞移动、`SpeechEnhancer.Config` 异常参数有限输出、`drainPCM` 遇 0 帧 `.inputRanDry` 安全结束。
  - `scripts/build_app.sh`：`CFBundleVersion` 由 `22` 递增至 `23`。
