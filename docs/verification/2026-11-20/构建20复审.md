2026-11-20，三位审查成员分别复核录音恢复、桌面交互和纠正功能。新测试包位于 `dist/听笺.app`，日常安装为构建 18。两个应用包均复核构建号，并通过严格签名校验。

| 复审发现 | 处理 |
| --- | --- |
| 暂停后点击继续，紧接着切换麦克风，旧相位可能让新音源保持停用 | 在输入操作队列中读取实际相位。继续期间请求结束时，迟到的继续结果不会把界面切回录音中。 |
| 换麦或继续成功后，设备断开的提示可能仍显示 | 输入故障使用独立提示。恢复成功后清除输入提示，识别故障仍由识别状态呈现。 |
| 中文模型下载完成时，稍早的模型查询可能覆盖新状态 | 下载成功后重新启动仍在准备模型的识别，并忽略旧查询。 |
| 关闭文字纠正后，手动触发会收到未配置服务的误导性提示 | 提示已关闭，并指明启用位置。 |
