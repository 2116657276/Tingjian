# 构建 20 桌面探索评审

2026-11-20，在 Apple 芯片 Mac 上直接操作构建 20 桌面应用。独立资料库只含合成音频和测试 Markdown。运行中的日常版构建 18 和正式资料保留原状。

## 已复现问题

| 优先级 | 操作与结果 | 处置建议 |
| --- | --- | --- |
| P1 | 在带有有效音频引用的「回听边界.md」内确认时间戳可用，从项目乙将文稿移到项目甲。移动面板只显示文稿名，落盘也只移动文稿，原 M4A 留在项目乙。此次隔离路径同时有 `/tmp` 与 `/private/tmp` 两种表示。单独验证确认目录枚举和传入 URL 使用不同路径字符串，解析后指向同一文件。 | 识别配对时使用一致的路径身份，移动前明确列出音频和文稿。在不同路径表示和同目录存在多个项目文件时补验移动范围。 |
| P1 | 把「示例录音」的音频改名为「录音]第二版」。应用接受名称，并将文稿写为 `![[录音]第二版.m4a]]`，随后文稿显示「未找到关联音频」。再移动文稿会把同一份录音拆到两个项目。 | 统一录音命名、重命名与 Markdown 引用规则。保存或重命名成功前确认引用可回读。 |
| P2 | 文稿中点有效时间戳，播放进度从零跳到 10 秒。关闭播放器后，仍显示原音频名，全部时间戳却变灰并提示「没有可定位的关联音频」。「更多 → 打开关联音频」出现在独立音频页，离开了当前阅读场景。另测 26 秒音频的 70 秒时间戳，也收到同一提示。 | 有效时间戳可以原地重新载入音频并定位。超过时长时显示具体原因。 |
| 体验 | 课程名填「网络实验第 1 讲」，录音期间显示课程名。保存后标签和侧栏使用「日期时间_网络实验第 1 讲」，Markdown 标题仍为课程名。复核了已有反馈。 | 让录音列表和文稿标签优先显示课程名，日期可作为辅助信息。磁盘命名可单独保留。 |

## 通过的桌面操作

- 首次设置、中文模型就绪提示、具名合成录音、暂停、继续和结束。暂停时计时停在约 20 秒，结束后自动打开文稿和对应音频，最终 M4A 约 24.8 秒。
- 将普通音频名改为「录音回听-已改名」后，标签和文稿引用当次更新，时间戳继续可用。该场景未复现改名后需要手动刷新。
- 强制终止独立测试进程时本地 CAF 已有约 7.8 秒。重启出现「恢复并保存」入口，交付 M4A 和 Markdown，文稿标明录音曾中断。
- 两个移动失败样本均核对了磁盘位置，两份音频都保留在原项目。

真实麦克风、AirPods、课堂识别、实际网关和云同步仍待专项验收。问题修复前建议维持现有私测范围。
