# 架构与数据流

- **工作区。** SwiftUI 侧栏展示资料库和持久化录音草稿，顶部标签对应文稿与音频。侧栏和当前内容独立刷新。ProjectLibrary 串行执行磁盘管理操作。目录列表按需读取，改名和移动完成后由 AppModel 更新当前路径状态。
- **文稿和播放。** 后台读取 Markdown、时间戳与音频链接。正文和关联音频独立加载。AVPlayer 管理当前音频，切换标签保存进度。
- **录音与恢复。** 音频先写本地 CAF，确认文字追加到 JSONL。会话描述记录启动时固定的保存目标、草稿关联和恢复状态。结束时导出音频，AAC 不可用时保留 CAF。
- **录音交付。** 普通录音在目标父目录暂存后整目录发布。已绑定草稿的录音在同卷暂存后写入原占位目录，发布记录支持中断后接续。交付标识用于识别发布后中断的会话。文件系统发布和 iCloud 跨设备传播分别验收。

**文字纠正。** 客户端按连续段落分批发送，校验返回的段落 ID 和顺序，再关联原时间戳并另存校正版。轻度清理和全面书面化各自缓存结果。
