## 2. 本轮评审发现并已修复的 A 类问题（构建 28）

1. **【构建 28 已修复】`DocumentDetail.actionBar` 窄窗未真正折行**
   - **位置**：[ContentView.swift](../../Sources/Tingjian/ContentView.swift) `DocumentDetail.actionBar`
   - **问题**：原 `ViewThatFits(in: .horizontal)` 的宽/窄两个分支均将全部 5 个操作按钮放在同一行 `HStack` 中，620pt 窄窗下存在挤压裁切风险。
   - **修复**：拆分为 `primaryActionButtons`（纠正文本 / 查看原稿 / 打开校正版 / 重新转写）与 `secondaryActionButtons`（查找 / 外部打开），宽窗单行合并展示，窄窗自然折成两行。

2. **【构建 28 已修复】顶栏上下文胶囊缺少宽度上限**
   - **位置**：[ContentView.swift](../../Sources/Tingjian/ContentView.swift) `ContentView.header`
   - **问题**：当打开了文件标签且当前位于长课程名录音页/目录页时，左侧上下文胶囊未限宽，容易挤占右侧 `tabBar`。
   - **修复**：为胶囊标题增加 `.frame(maxWidth: 160, alignment: .leading)` 与尾部省略，保障标签栏空间。

3. **【构建 28 已修复】校正版隐藏空时间锚点时，播放进入空段会导致当前句高亮短暂消失**
   - **位置**：[AppModel.swift](../../Sources/Tingjian/AppModel.swift) `updateActiveDocumentBlock(at:)` 与 [ContentView.swift](../../Sources/Tingjian/ContentView.swift) `DocumentDetail`
   - **问题**：`TranscriptLocator.activeBlockIndex` 此前基于全部 `doc.blocks`（含已隐藏的校正版空锚点）计算，音频播到被隐藏空段的时间点时，界面当前高亮段落会突然熄灭。
   - **修复**：将 `showEmptyCorrectedSegments` 提升至 `AppModel`（切换文稿自动复位并在开关切换时立即重算），隐藏空段时仅对可见非空块做二分定位。

4. **【构建 28 已修复】点击清理本地备份仍在主线程同步扫盘与移入废纸篓**
   - **位置**：[AppModel.swift](../../Sources/Tingjian/AppModel.swift) `trashSavedBackupsAsync()`、[SettingsView.swift](../../Sources/Tingjian/SettingsView.swift)
   - **问题**：虽然本地备份统计展示已改为后台异步，但点击「移入废纸篓」按钮仍同步遍历 `localRoot` 并逐个 `trashItem`。
   - **修复**：新增带防重入状态 `isTrashingBackups` 的 `trashSavedBackupsAsync()`，在后台完成移入废纸篓与剩余容量重算，按钮清理中显示「正在清理…」并禁用。

5. **【构建 28 已修复】「查看原稿」按钮未核验文件仍存在**
   - **位置**：[AppModel.swift](../../Sources/Tingjian/AppModel.swift) `originalDocumentURL(for:)`、[ContentView.swift](../../Sources/Tingjian/ContentView.swift)
   - **问题**：外部（Finder/Obsidian）删掉原稿后，缓存的 `openDocument.originalDocument` 仍会显示「查看原稿」按钮，点击后落入错误页。
   - **修复**：统一经 `originalDocumentURL(for:)` 校验文件仍存在于磁盘后再展示入口。
