# 课堂验收清单

适用于 `1.0.2`（当前稳定版与测试版均为构建 32）。建议先在隔离目录完成 5 分钟真机硬件预检，再进入 45–90 分钟真实课堂连续试用。

## 一、课前准备与硬件预检（真机）

- [ ] 确认运行环境为 macOS 26.0 及以上，中文识别模型显示「已就绪」，保存路径正确。
- [ ] 开课前授权麦克风，确认输入电平条随讲话实时变化，且不修改系统默认输入设备。
- [ ] **合盖 + 内置麦拦截实测（MacBook Pro 真机）**：
  - 开盖使用内置麦克风：正常开始录音并出字；
  - 合盖且选定内置麦克风（含「系统默认」实际指向内置麦）：点击开始/继续或切换时被拦截，并提示打开屏幕或改用外接设备；
  - 合盖但使用外接耳机/麦克风：正常开始并持续录制。
- [ ] **真实麦克风弱音试录（3–5 分钟）**：用 MacBook 内置麦及常用耳机在低音量/远讲条件下试录，记录首字出现时间、明显漏识时段与回听音质。

## 二、课中录制与防事故

- [ ] 录音进行中在转写页顶部补填或修改课程名称（含带空格名称与中文输入法），停录后确认交付文件夹、M4A、Markdown 文件名与标题均按最新课程名生成。
- [ ] 在底栏临时切换到另一个输入设备，回听切换前后，确认 Markdown「说明」记录了设备名与切换时间。
- [ ] 录音中让当前设备断开（或拔掉），确认转为暂停而不是结束或悄悄改用其他麦克风；更换或重连设备后能继续录，也可直接结束保存已录部分。
- [ ] 确认**持续静音提醒**：静音或遮挡麦克风约 45 秒后顶部出现温和提醒且不中断录音，恢复讲话后提醒自动消除。
- [ ] 录制超过 30 秒后测试防误停：点「结束」或按 `⌘⇧E` 时弹出确认框；选「继续录音」不中断，选「结束并保存」正常收尾交付。
- [ ] 录制一节真实课程（30–90 分钟），中途暂停约 20 秒再继续，确认计时暂停、音频不含暂停片段；观察长时 CPU、内存占用、发热以及最终文字是否存在重复堆叠、整段覆盖或系统性丢句尾。

## 三、课后阅读、回听、纠正与工作区管理

- [ ] 结束后等待保存完成，无需手动导出即可在侧栏找到新课目录（默认按「最新录音优先」置顶，侧栏两行显示课程名与紧凑日期副标）及 M4A、Markdown。
- [ ] 检查文稿顶部元信息（录制日期、时长、关联音频、转写状态徽章）与「说明」条；若存在缺口，确认正文行内出现 `> ⚠` 警示卡片且点击时间可直接播放该区间。
- [ ] 测试课后回听四件套：点击文稿时间戳直接定位并播放、当前段落自动高亮、开启「跟随播放滚动」、非输入态空格键播停、`⌘[` 快退 5 秒、`⌘]` 快进 10 秒、切换 `1.0x–2.0x` 倍速播放；核对开头、中间、末尾时间戳对应准确。
- [ ] 按 `⌘F` 页内查找关键词，验证命中计数与 `⌘G` / `⌘⇧G` 上下跳转。
- [ ] 在侧栏新建项目、重命名一份带日期前缀的录音目录（确认默认保留日期前缀且可勾选「同步更换直属文件名前缀」）并移动一份录音，确认 Finder 路径与 Markdown 内 `![[...]]` 引用一致、音频与文稿未被拆散。
- [ ] 在音频详情页或文稿顶栏触发「重新转写」，确认另存 `_重转写.md` 且不覆盖原稿。
- [ ] 可选：点击文稿顶栏「纠正文本」，确认另存 `_校正版.md`、原稿保留、校正版可点「查看原稿」互跳，删空的语气词锚点默认折叠且可切换显示；使用「外部打开」核对 Obsidian 协同。

## 四、异常兜底与云同步（单独短录音验证）

- [ ] 模拟目标保存失败，确认界面给出本地恢复路径（可找到 CAF、会话信息与已确认文本），支持重试保存或更换保存位置；待重试状态下按 `⌘Q` 退出时确认有温和提示。
- [ ] 用短录音测试异常中断（强退）后重启恢复，确认恢复后保留音频、已确认文字及中断前实时草稿（若当时尚未最终确认），且标注「部分完成」并引导重新转写。
- [ ] 在另一台设备确认 iCloud 文件确已同步；应用的「已写入目录」仅表示本地写入完成，不作为云同步证明。若开启了「优化 Mac 储存空间」，整理或回听前先确认音频已下载到本地（非 `.icloud` 占位）。

异常退出、睡眠、合盖与设备断连建议另做短录音验证，避免用唯一的重要课堂录音测试故障。
