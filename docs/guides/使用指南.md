# 使用指南

运行环境要求 macOS 26.0 及以上。稳定使用版位于 `/Applications/听笺.app`，项目内 `dist/听笺.app` 为测试版，当前版本与已验收范围以 [当前版本与验收状态](../project/当前版本与验收状态.md) 为准。正式保存位置默认指向 iCloud Obsidian 的听笺目录，可在首次设置或设置窗口修改。课程名可留空，点击开始才采集麦克风；首次使用按系统提示授权。暂停期间不采集，继续后时长累加。结束后等待保存状态完成，再打开文件夹。

## 项目工作区

保存位置就是资料库根目录，左侧直接显示磁盘上的文件夹与文件，不使用数据库。录音在草稿指定的保存位置生成独立文件夹；应用会在后台轻量探测一级子目录是否含有直属音频，未展开文件夹时侧栏也可显示录音标记（波形图标与红点）。支持的音频为 m4a、caf、wav、aiff、aif、mp3，文稿为 md；其他文件与隐藏文件不显示，但改名或移动时不会被删除。

点击侧栏「资料库根目录」可浏览根目录。展开文件夹时读取其子项。侧栏支持按「最新录音优先」（默认：普通项目按名称升序在前，带日期前缀的录音按时间倒序置顶）或「按名称升序」排列，可在侧栏顶部排序按钮或空白处右键切换。带日期前缀的录音目录与文件在侧栏（两行显示课程名与紧凑日期副标）、目录详情、音频详情、顶栏与标签页中统一按课程名与日期呈现，同时磁盘保留完整日期前缀以防重名。

侧栏刷新重读根目录和已展开的分支，顶部刷新重读当前内容，两处各自显示进度。上方按钮可新建录音、新建项目、切换排序与刷新；下方是设置和保存位置入口。应用重新激活、手动刷新以及应用自身的改名、移动、保存后都会刷新对应目录，不做后台轮询。根目录不存在时显示空资料库，第一次录音或新建项目时才创建；无权限或目录不可读会显示实际路径和错误。

重命名：选中侧栏行或文档页操作，也可用 `⌘⇧R`。文件名保留扩展名，非法名称、方括号、重名、点目录、符号链接和根目录改名都会被拒绝（APFS 上支持仅改字母大小写）。已有包含方括号的音频引用仍可读取。改名音频或文稿时，同一目录中由本应用写入的 `[[名称]]`、`![[名称]]` 引用（包括校正版的“原始转写”链接）会同步更新；写入失败会回滚文件与文稿字节，回滚失败会列出实际路径。重命名带 `yyyy-MM-dd_HH-mm-ss` 日期前缀的录音目录时，默认仅编辑课程名部分并自动保留日期前缀；面板首位可勾选「同步更换直属文件名前缀」（仅替换直属文件名中与原项目名相同的开头，不修改子文件夹与正文），如需连日期前缀一起改，可再勾选下方的「编辑完整磁盘名称」（移除日期前缀后该文件夹将不再按时间线排序）。普通目录改名默认只改变文件夹名。

移动：可将侧栏条目拖到资料库根目录或项目目录，也可右键选择「移动到…」。移动配对文稿或音频前会列出随行文件。独立录音文件夹整体移动，混放的项目只移动配对文件。普通目录或独立文件按自身移动。目标为自身、子目录、资料库外、同名或符号链接时拒绝；同一父目录返回原位置。

录音、收尾、待重试保存的目标目录及祖先、未完成会话的绑定占位目录，以及正在重新转写的音频和正在纠正的源文稿，不能被改名或移动；录音进行中界面也会禁用这些操作，重新转写或文字纠正进行中不可开始新录音。外部移动或删除当前选中文件时，主区显示“文件已移动或不存在”，用顶部刷新按钮重新读取。

iCloud「优化 Mac 储存空间」边界：若系统将 iCloud 目录中的音频文件驱逐为云端占位（隐藏的 `.icloud` 文件），本应用按纯本地文件系统扫描且跳过隐藏文件，此时可能提示“未找到关联音频”，或在混放目录移动、文件改名时漏同步云端占位文件。整理、回听或重新转写前，请先在 Finder 中将对应录音文件夹下载到本地。

## 录音草稿与输入设备

「新建录音」或 `⌘N` 新建根目录草稿。要存进某个项目，打开项目并选「在此录音」。草稿页显示保存位置，可点「改存到根目录」切回。浏览或新建项目时，已打开的草稿保留各自的录音目标。

将侧栏「暂存」中的草稿拖到根目录或项目，即可创建并绑定录音文件夹。再次拖放会移动原空目录。也可在草稿页选择保存位置。关闭草稿会保留文件夹。判空与交付校验会自动忽略 Finder 生成的 `.DS_Store`；若绑定目录被删除、替换或写入了其他文件，录音前可重选位置，录音后可在保存提示里更换位置并重试。

草稿平铺在侧栏「暂存」，位于资料库根目录和项目树之间；没有草稿时自动隐藏「暂存」标题。顶部标签用于切换文稿和音频。点击暂存区中的一份草稿后，可在「课程名称」中命名；关闭未开始的草稿会删除它。退出时仍打开的草稿会在重启后恢复。录音期间可以准备其他草稿，同时只能进行一次录音。「回到当前录音」可返回本次会话，录音成功后移除对应草稿。

空白录音页中央显示当前保存位置，长路径会自动换行。当前用户的家目录显示为 `~`，例如 `~/Documents/听笺`。按住 `⌘` 单击蓝色路径或双击路径，可以在 Finder 中打开该目录。目录不可用时会显示提示。在录音页中央填写课程名称后，点击「开始录音」或按 `⌘↩`。课程名称可留空。

在「设置 → 录音输入」选择长期默认设备。「系统默认」在录音开始时取当前系统输入。使用最下方状态栏的麦克风菜单可临时换麦。空闲时只影响下一次成功开始的录音，录音或暂停时只影响本次会话。切换期间没有采集，时间轴上也没有插入静音。文稿会记录切换前后的设备及时间。暂停中切换后，需要手动继续才会恢复采集。

当前设备断开时录音转为暂停并显示补救入口，不会结束录音或悄悄改用别的麦克风；继续或更换设备后可接着录，也可以直接结束保存已录部分。运行时的输入错误只尝试用同一设备重建一次，失败即暂停。权限只在点击开始时申请；无设备或权限被拒绝会保持空闲并说明原因。开始、暂停、继续与切换的操作串行执行，重复点击不会启动多个音源。

保存目标在开始录音时固定：之后更改设置中的保存位置不会影响本次会话，保存、重试和异常退出后的恢复都使用开始时的目标。待保存或保存失败时禁止开始新录音，先重试保存，避免丢掉本地补救入口。

## 转写与保存

默认使用 Apple SpeechAnalyzer / SpeechTranscriber 的简体中文模型。首次设置和「设置 → 保存与恢复」均提供模型下载入口。模型不可用或转写异常时，录音仍可保存；不要将“部分完成”当作完整转写。无论实时录音还是重新转写，若未识别出任何文字（如静音、设备无有效输入或音频过弱），状态均如实标为「部分完成」并附说明。录音结束后如需补转，可在音频详情页、文稿页顶栏、侧栏/目录音频右键菜单或「设置 → 保存与恢复」中执行「重新转写」，结果另存为 `_重转写.md`（重名自动追加序号），不覆盖原稿。

默认目标：`~/Library/Mobile Documents/iCloud~md~obsidian/Documents/听笺`。设置中可改目录。每次会话包含 M4A 和带时间戳的 Markdown；校正版另存。状态“已写入目录”只表示本地写入结果，不表示云端同步完成，云同步情况在状态详情中不承诺。

本地恢复目录：`~/Library/Application Support/听笺/Sessions`。录音过程中持续保存 CAF、会话信息、确认转写日志与节流实时草稿快照；目标目录写入失败时保留本地内容，可重试；转换失败时保留 CAF。异常退出后重启会在状态详情逐份列出未完成会话，提示恢复并保存（若中断前存在尚未最终确认的实时文字，会保留末段草稿并标为「部分完成」引导重新转写）。已成功交付的本地备份可在设置中查看总容量并移入废纸篓。

如果出现“文本/恢复信息保存异常”，音频会继续保存，界面显示本地路径；应用会在定期保存和结束时尝试重建日志。异常未解除前不要把全部内容视为保存成功。开始准备失败不会启动麦克风。

录音中退出会询问结束并保存或继续录音；选“继续录音”会取消本次退出并恢复窗口。选“结束并保存”后，成功写入目标目录才会退出。写入失败时可在窗口中重试或更换位置；处于待重试保存状态按 `⌘Q` 退出时也会弹出温和确认提醒（本地恢复目录完好，下次打开可继续恢复）。睡眠与合盖仍不承诺持续录音。

## 文稿阅读与播放

主区一次只显示一份文稿或音频。文稿页顶部展示标题、转写状态徽章（含「部分完成」「转写失败」「校正版」及模型名）、录制日期、时长、关联音频与说明条，并提供「纠正文本」「查看原稿 / 打开校正版」「重新转写」「查找（`⌘F`，仅带时间戳转写稿显示）」「外部打开」等高频入口。文稿中的 `[HH:MM:SS] 文本` 以 16pt 正文显示，`> ⚠` 转写不完整区间在正文行内以警示块呈现（可点击时间直接播放该区间）；校正版删空后的空时间锚点默认折叠隐藏（原文件保持不变，可原地切换显示）。

点击时间戳会定位并直接播放关联音频的对应位置，播放时自动高亮当前段落并支持开启「跟随播放滚动」；控制带和顶部「播放」菜单支持快退 5 秒（`⌘[`）、快进 10 秒（`⌘]`）、`1.0x–2.0x` 倍速播放，主窗口非输入态且无设置窗/弹窗时可按空格键播停。在音频详情页关闭底栏播放器后，页面顶部会直接提供「播放音频」按钮以便续播。超出音频时长、没有关联音频或正在录音时不可定位。引用 `![[音频文件名]]` 指向同目录实际存在的音频时才加载播放器；缺失时会说明，但文稿仍可阅读。没有时间戳的普通 Markdown 显示原文，不猜配对、不丢弃内容，且不提供页内查找。应用只有一个播放器，换文件会停止旧音频。

## 主题与设置

设置分“外观”“录音输入”“保存与恢复”“文字纠正”。外观可选跟随系统、浅色、深色，立即生效并在重启后保留；主窗口与设置窗口同步。浅色为纯白纸面，深色为深灰纸面，状态同时使用图标与文字。本地备份区展示已交付备份份数与磁盘总占用。关闭“启用文字纠正”时会收起下方网关详细配置。

录音进行中可在转写页顶部随时补填或修改课程名称，结束快捷键为 `⌘⇧E`（录制超过 30 秒时提示确认防误停）。若确认 Mac 已合盖且所选输入（含「系统默认」实际指向）为内置麦克风，应用会拒绝开始或继续录音并引导更换外接麦克风或耳机；录音中连续 45 秒未检测到有效输入声音且无新转写时，顶部会出现柔和提醒而不中断录音。

首次打开时可确认保存位置，并选择是否启用文字纠正。已有保存位置或网关设置会带入引导。纠正方式默认是「轻度清理」，也可以在「设置 → 文字纠正」选择「全面书面化」。两种方式都保留原稿和时间戳。

## 文字纠正网关

在「设置 → 文字纠正」选择 DeepSeek 官方、Magpie 或填写兼容 Chat Completions 的自定义地址。初始配置使用本机 Magpie 和 `sdu/ByteDance-volcengine/DeepSeek-V4.1-Flash`（DeepSeek 官方默认模型为 `deepseek-flash`）。从旧版升级时会保留原地址和模型，原钥匙串密钥仅用于原配置地址。

DeepSeek 官方需要 API Key，本机 Magpie 通常可以留空。填写后点击「保存密钥」，密钥按 API 地址存入系统钥匙串。清空输入并保存后，该地址会以无密钥方式连接。切换网关或修改地址后，点击「刷新模型」读取当前清单，成功后显示模型数量。清单缺失时可手填模型 ID。

「自动」使用当前模型公布的最低推理强度，例如模型支持 `low` 和 `high` 时使用 `low`。已读取的档位会保存在本地，内置默认模型可直接使用 `low`。手动选择的档位用于当前会话，切换模型或网关后恢复自动。自定义模型的服务未提供档位时，可以手填，留空使用服务默认。[DeepSeek 模型列表文档](https://api-docs.deepseek.com/api/list-models/)

点击「纠正文本」后，当前网关会收到所选文稿的转写文字、资料库内的项目和录音目录名（根目录直放文稿不带库外父目录名）、文稿名及文稿开头信息（自动剔除 `## 说明` 段，避免发送本机路径）。长文会分批发送并提取上下文，后续批次也会参考相邻段落。请求只使用文本，原录音和逐段时间锚点留在本机。校正结果与上下文摘要会写入本机缓存。模型把每批相邻段落连起来校正，再按原顺序分回各段。后一批可以参考前一批已保留的文字来清理重复。删空的段落仍保留时间戳。模型明确因长度截断时，会把多段块对半拆分重试。拒绝回答、HTTP 错误、格式不合法、段落数量或 id 顺序不一致都会失败，不自动修复、不改写原稿。写出前会重读原稿，若被外部修改会提示重新纠正。全部成功后才另存 `_校正版.md`；原稿与录音不受影响。一次只运行一个纠正任务，进度按已完成原文段数显示；切换到其他文稿不会串进度。
