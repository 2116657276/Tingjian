# 使用指南

稳定使用版位于 `/Applications/听笺.app`，项目内 `dist/听笺.app` 为测试版，版本以「当前版本与验收状态」为准。正式保存位置沿用 iCloud Obsidian 的听笺目录。课程名可留空，点击开始才采集麦克风；首次使用按系统提示授权。暂停期间不采集，继续后时长累加。结束后等待保存状态完成，再打开文件夹。

## 项目工作区

保存位置就是资料库根目录，左侧直接显示磁盘上的文件夹与文件，不使用数据库。录音在草稿指定的保存位置生成独立文件夹；读取到文件夹含有直属音频后，侧栏显示录音标记。支持的音频为 m4a、caf、wav、aiff、aif、mp3，文稿为 md；其他文件不显示，但改名或移动时不会被删除。

点击侧栏「资料库根目录」可浏览根目录。展开文件夹时读取其子项。侧栏刷新重读根目录和已展开的分支，顶部刷新重读当前内容，两处各自显示进度。上方按钮可新建录音、新建项目与刷新；下方是设置和保存位置入口。应用重新激活、手动刷新以及应用自身的改名、移动、保存后都会刷新对应目录，不做后台轮询。根目录不存在时显示空资料库，第一次录音或新建项目时才创建；无权限或目录不可读会显示实际路径和错误。

重命名：选中侧栏行或文档页操作，也可用 ⌘⇧R。文件名保留扩展名，非法名称、重名、点目录、符号链接和根目录改名都会被拒绝。改名音频或文稿时，同一目录中由本应用写入的 `[[名称]]`、`![[名称]]` 引用（包括校正版的“原始转写”链接）会同步更新；写入失败会回滚文件与文稿字节，回滚失败会列出实际路径。目录改名默认只改变文件夹名；重命名面板可勾选“同步更换直属文件名前缀”，仅替换直属文件名中与原项目名相同的开头，不修改子文件夹与正文。

移动：可将侧栏条目拖到资料库根目录或项目目录，也可右键选择「移动到…」。配对文稿和音频按整份录音移动，避免拆散音频与配对文稿；普通目录或独立文件按自身移动。目标为自身、子目录、资料库外、同名或符号链接时拒绝；同一父目录返回原位置。

录音、收尾、待重试保存的目标目录及祖先，以及正在纠正的源文稿，不能被改名或移动；录音进行中界面也会禁用这些操作。外部移动或删除当前选中文件时，主区显示“文件已移动或不存在”，用顶部刷新按钮重新读取。

## 录音草稿与输入设备

「新建录音」或 ⌘N 新建根目录草稿。要存进某个项目，打开项目并选「在此录音」。草稿页显示保存位置，可点「改存到根目录」切回。浏览或新建项目时，已打开的草稿保留各自的录音目标。

将侧栏「暂存」中的草稿拖到根目录或项目，即可创建并绑定录音文件夹。再次拖放会移动原空目录。也可在草稿页选择保存位置。关闭草稿会保留文件夹。若绑定目录被删除、替换或写入了其他文件，录音前可重选位置，录音后可在保存提示里更换位置并重试。

草稿平铺在侧栏「暂存」，位于资料库根目录和项目树之间。顶部标签用于切换文稿和音频。点击暂存区中的一份草稿后，可在「课程名称」中命名；关闭未开始的草稿会删除它。退出时仍打开的草稿会在重启后恢复。录音期间可以准备其他草稿，同时只能进行一次录音。「回到当前录音」可返回本次会话，录音成功后移除对应草稿。


空白录音页中央显示当前保存位置，长路径会自动换行。当前用户的家目录显示为 `~`，例如 `~/Documents/听笺`。按住 ⌘ 单击蓝色路径或双击路径，可以在 Finder 中打开该目录。目录不可用时会显示提示。在录音页中央填写课程名称后，点击「开始录音」或按 ⌘↩。课程名称可留空。
设置或录音控制带中的输入设备按系统 uniqueID 固定，不修改系统默认设备。“系统默认（开始时固定）”只在开始录音时解析一次默认设备。录音中可以直接切换设备：同一份录音继续，切换期间不产生音频，也不插入虚构静音；结束后 Markdown 的“说明”会记录原设备、新设备与切换时间。暂停中切换设备不会自行开始采集。

当前设备断开时录音转为暂停并显示补救入口，不会结束录音或悄悄改用别的麦克风；继续或更换设备后可接着录，也可以直接结束保存已录部分。运行时的输入错误只尝试用同一设备重建一次，失败即暂停。权限只在点击开始时申请；无设备或权限被拒绝会保持空闲并说明原因。开始、暂停、继续与切换的操作串行执行，重复点击不会启动多个音源。

保存目标在开始录音时固定：之后更改设置中的保存位置不会影响本次会话，保存、重试和异常退出后的恢复都使用开始时的目标。待保存或保存失败时禁止开始新录音，先重试保存，避免丢掉本地补救入口。

## 转写与保存

默认使用 Apple SpeechAnalyzer / SpeechTranscriber 的简体中文模型。模型不可用或转写异常时，录音仍可保存；不要将“部分完成”当作完整转写。没有文字也可能是静音。设置中可从已保存录音重新转写，另存文件；重名时自动追加序号，保留已有编辑。

默认目标：`~/Library/Mobile Documents/iCloud~md~obsidian/Documents/听笺`。设置中可改目录。每次会话包含 M4A 和带时间戳的 Markdown；校正版另存。状态“已写入目录”只表示本地写入结果，不表示云端同步完成，云同步情况在状态详情中不承诺。

本地恢复目录：`~/Library/Application Support/听笺/Sessions`。录音过程中持续保存 CAF、会话信息和会话日志；目标目录写入失败时保留本地内容，可重试；转换失败时保留 CAF。异常退出后重启会提示恢复并保存。已成功交付的本地备份可在设置中移入废纸篓。

如果出现“文本/恢复信息保存异常”，音频会继续保存，界面显示本地路径；应用会在定期保存和结束时尝试重建日志。异常未解除前不要把全部内容视为保存成功。开始准备失败不会启动麦克风。

录音中退出会询问结束并保存或继续录音；选“继续录音”会取消本次退出并恢复窗口。睡眠与合盖仍不承诺持续录音。

## 文稿阅读与播放

主区一次只显示一份文稿或音频。文稿中的 `[HH:MM:SS] 文本` 以 16pt 正文显示，点击时间戳会定位到关联音频的对应位置；超出音频时长、没有关联音频或正在录音时不可定位。引用 `![[音频文件名]]` 指向同目录实际存在的音频时才加载播放器；缺失时会说明，但文稿仍可阅读。没有时间戳的普通 Markdown 显示原文，不猜配对、不丢弃内容。应用只有一个播放器，换文件会停止旧音频。

## 主题与设置

设置分“外观”“录音输入”“保存与恢复”“文字纠正”。外观可选跟随系统、浅色、深色，立即生效并在重启后保留；主窗口与设置窗口同步。浅色为暖白纸感，深色为墨绿纸面，状态同时使用图标与文字。

首次打开时可确认保存位置，并选择是否启用文字纠正。已有保存位置或网关设置会带入引导。纠正方式默认是「轻度清理」，也可以在「设置 → 文字纠正」选择「全面书面化」。两种方式都保留原稿和时间戳。

## 文字纠正网关

在「设置 → 文字纠正」选择 DeepSeek 官方、Magpie 或填写兼容 Chat Completions 的自定义地址。初始配置使用本机 Magpie 和 `sdu/ByteDance-volcengine/DeepSeek-V4.1-Flash`。从旧版升级时会保留原地址和模型，原钥匙串密钥仅用于原配置地址。

DeepSeek 官方需要 API Key，本机 Magpie 通常可以留空。填写后点击「保存密钥」，密钥按 API 地址存入系统钥匙串。清空输入并保存后，该地址会以无密钥方式连接。切换网关或修改地址后，点击「刷新模型」读取当前清单，成功后显示模型数量。清单缺失时可手填模型 ID。

「自动」使用当前模型公布的最低推理强度，例如模型支持 `low` 和 `high` 时使用 `low`。已读取的档位会保存在本地，内置默认模型可直接使用 `low`。手动选择的档位用于当前会话，切换模型或网关后恢复自动。自定义模型的服务未提供档位时，可以手填，留空使用服务默认。 [DeepSeek 模型列表文档](https://api-docs.deepseek.com/api/list-models/)

纠正以当前打开的文稿为单位：只在你点击“纠正文本”时发送该文稿的转写文字，不发送录音与时间戳。请求与回复都是 `{"items":[{"id":1,"text":"..."}]}`，客户端保留原时间戳。模型把每批相邻段落连起来校正，再按原顺序分回各段。后一批可以参考前一批已保留的文字来清理重复。删空的段落仍保留时间戳。模型明确因长度截断时，会把多段块对半拆分重试。拒绝回答、HTTP 错误、格式不合法、段落数量或 id 顺序不一致都会失败，不自动修复、不改写原稿。写出前会重读原稿，若被外部修改会提示重新纠正。全部成功后才另存 `_校正版.md`；原稿与录音不受影响。一次只运行一个纠正任务，进度按已完成原文段数显示；切换到其他文稿不会串进度。
